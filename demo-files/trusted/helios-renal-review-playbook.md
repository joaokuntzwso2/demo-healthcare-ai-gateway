# Synthetic Helios Renal Medication-Review Playbook
Publisher: Helios Clinical Governance

Demonstration content only. This is not clinical guidance and must not be used for patient care.

For a renal medication-review workflow, the application should retrieve recent and prior laboratory evidence from the authoritative laboratory source, retrieve the current medication and allergy records when permitted by purpose and scope, and make the provenance visible to the clinician. Generated narrative must not replace the source observations. Any medication change remains a request that requires deterministic demo-safety evaluation and external clinician approval.
